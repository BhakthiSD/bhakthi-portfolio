# Bhakthi S — Developer Portfolio

A responsive, static portfolio for Bhakthi S, a Software Engineer focused on backend-heavy full-stack development. Built with Vue 3, Vite and TypeScript.

## Development

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
npm run build
npm run preview
```

`npm run lint` checks JavaScript, TypeScript and Vue files. `npm run format` formats the project with Prettier.

## Configuration

Copy `.env.example` to `.env` and set the public profile values:

```env
VITE_SITE_URL=https://your-domain.example
VITE_LINKEDIN_URL=https://www.linkedin.com/in/your-profile
VITE_GITHUB_URL=https://github.com/your-profile
VITE_EMAIL=you@example.com
VITE_RESUME_URL=/resume/Bhakthi-S-Resume.pdf
```

These values are public, so do not put secrets in them. Set `VITE_SITE_URL` for production: the Vite build then adds canonical and Open Graph URL metadata and generates domain-specific `robots.txt` and `sitemap.xml` files in `dist/`. Without a site URL, no canonical URL or sitemap is emitted.

## Resume

Place the real PDF at `public/resume/Bhakthi-S-Resume.pdf` and set `VITE_RESUME_URL` to its public path. If no URL is configured, the app checks the default path before presenting a download action. No resume content is generated by this project.

## Build and deploy

The production output is `dist/`. Vercel detects Vite automatically; no custom `vercel.json` is needed for this single-page landing page. Set the environment variables in the Vercel project settings, then deploy. The app uses section anchors and does not require client-side routing or SPA rewrite rules.

## Project structure

```text
src/
  App.vue       Page sections and navigation
  data.ts       Profile, skills and project content
  main.ts       Application entry point
  style.css     Responsive design and motion preferences
public/         Static SEO files and favicon
```

Update `src/data.ts` to change profile links, skill groups and project cards. Education and resume details intentionally remain unfilled until the accurate information and PDF are available.
